# Jobs

**What this folder is for:** step-by-step instructions for work Claude does more than once. Each job lists the notes Claude should read *before* starting, so it has the right context first.

**Adding a job:** copy [[Job Template]] from [[Templates]] into this folder, fill it in, and add a line below.

## Contents
- [[Checkpoint]] — Write a dated entry in today's daily note covering what was done, decided and left open.
- [[Evening Wrap-up]] — Runs daily at 6 PM: fills in today's daily note from the day's file changes and keeps today's indexes right.
- [[Weekly Tidy-up]] — Runs Sundays at 6:30 PM: fixes folder indexes and broken links, checks the backup, flags stale items, and leaves a review in Inbox.
