# Checkpoint

**When to run:** when I say "checkpoint", at the end of a work session, or before a long conversation is cleared.

## Read first
- Today's note in [[Daily Notes]], if it already exists.
- [[Active Priorities]].

## Steps
1. Check the actual date and time on the computer. Don't assume them; a conversation can stay open overnight.
2. Open `Daily Notes/YYYY-MM-DD.md` for today. If it doesn't exist, create it from [[Daily Note]].
3. Under `## Entries`, add `### HH:MM — <short title>` with these four parts:
   - **What Got Done:** what was finished.
   - **Still In Progress:** what's left, and where to pick it up.
   - **Decisions Made:** decisions and why.
   - **Notes Touched:** wiki links to every note created or changed.
4. Add one bullet to `## Index` at the top: `HH:MM — <one sentence>`.
5. If this is a new day, add the day to the Contents list in [[Daily Notes]].
6. Update open items where they live. Project items go in that project's Current Brief. Everything else goes in [[Active Priorities]]. Add a project to the Projects list there when it gets a Current Brief.
7. Give anything new a proper home too, not just a daily note entry. Update the relevant note (such as a project's Current Brief or Decision Log), or create one in the right folder and add it to that folder's index.
8. Read back what you changed to confirm it saved, then reply with the entry you wrote.
