# Active Priorities

The starting point for all open work. Each open item is written down in exactly one place.

**Rules**
- **Projects with a Current Brief** keep their own open items in that brief. This list only links to the brief, so the items are never copied in two places.
- **Everything else** (work without a project folder, one-off tasks, personal to-dos) is listed here under Open.
- When an item is done, check it off and move it to Completed with the date.
- A daily note's "Still In Progress" is a snapshot from that day and may be out of date. This list and the project briefs are the current record.
- Before acting on an item, check its real state first. It may already be done.
