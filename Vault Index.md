# Vault Index

The map of this vault. Claude reads this note at the start of every session instead of reading the whole vault, then opens other notes only when a task needs them.

New to this vault, or need a reminder how it works? Read [[How This Vault Works]].

**How to find things**
1. Pick the folder below that fits.
2. Read that folder's index note (it has the same name as the folder).
3. Open only the notes it points to.

## Open work
- [[Active Priorities]] — Starting point for open work: links to each project's Current Brief, plus everything that isn't part of a project. Check it at the start of a session.

## Folders
- [[Inbox]] — Drop zone: notes for Claude to act on, and Claude's drafts waiting for review.
- [[Daily Notes]] — One note per day with timestamped work entries. Search each day's `## Index` first.
- [[Projects]] — One subfolder per project, each with a Current Brief and a Decision Log. Active: [[Taskflow]].
- [[Jobs]] — Step-by-step instructions for recurring work, such as [[Checkpoint]].
- [[Reference]] — Knowledge shared across projects: style, how-tos, checklists.
- [[Personal]] — Personal projects, preferences and anything about me Claude should know.
- [[Templates]] — Starting layouts for daily notes and jobs.
- [[Attachments]] — Images and files pasted into notes. Obsidian fills it automatically.
- [[Archive]] — Inactive notes. Not searched unless asked.
