# Daily Notes

**What this folder is for:** one note per day, named `YYYY-MM-DD`. Claude adds a timestamped entry each time you run a [[Checkpoint]].

**How a daily note is laid out**
1. `## Index` at the top: one short bullet per entry. This is what Claude searches first.
2. `## Entries` below: the full write-ups, each under a `### HH:MM — Title` heading.

**To find something:** search the `## Index` sections first, then open only the days that match.

New daily notes start from [[Daily Note]] in [[Templates]].
