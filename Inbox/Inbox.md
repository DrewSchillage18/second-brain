# Inbox

**What this folder is for:** a drop zone in both directions.
- You drop notes here that you want Claude to read or act on.
- Claude drops drafts and new notes here for you to review before they're filed.

**Rules**
- Nothing lives here for good. Once something is reviewed, file it in the right folder or move it to [[Archive]].
- When Claude files a note, it also updates that folder's index note.
